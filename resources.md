## Free: Homelab security starter checklist

A short, general checklist for a home server. Tick each one off.

- [ ] Every service has a unique password, stored in a password manager (never in notes or chat).
- [ ] SSH uses keys, and password login is off.
- [ ] Management interfaces and monitoring APIs listen on localhost or sit behind authentication.
- [ ] Services reachable on the LAN are restricted with a host firewall.
- [ ] Guests and smart-home devices are on a separate network.
- [ ] Automation and bots run as their own low-privilege user, not as the account that holds your other secrets.
- [ ] Tokens are scoped to one repository, short-lived and on a rotation reminder.
- [ ] Important repositories require a pull request and review before changes reach the main branch.
- [ ] Backups exist and a restore has been tested.
- [ ] Updates are applied on a schedule.
- [ ] Notes and posts are scanned for passwords, tokens, IPs and names before anything is shared.
